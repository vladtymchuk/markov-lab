# Звіт про дефекти

| ID | Виявлення і вплив | Виправлення і перевірка |
|---|---|---|
| D01 | У DTMC з усіма завершеними траєкторіями нижня межа Вілсона для незавершення була додатною на 1,36×10⁻²⁰ через округлення | Для нульової та повної вибірки встановлено точні межі 0 і 1. Seeded тести обох ланцюгів проходять |

| D03 | Після помилки форми текст повідомлення додавався до доступної назви поля | Назву, опис помилки й ознаку некоректності визначено окремо. Компонентний тест проходить |

У цьому середовищі деякі shell-виклики підхоплювали Node.js 18, що спричиняло помилку PostCSS або відмову Playwright. Вебзастосунок перевірено у виробничому образі Node.js 22, а локальні тести запускалися з явним шляхом до Node.js 22. Це зафіксована особливість локального PATH.
