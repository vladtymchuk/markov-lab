# Математичні моделі

Порядок станів відповідає списку модулів, далі йдуть SUCCESS і FAILURE. Вектори є векторами-рядками. Ідентифікатор стану стабільний у межах версії.

## Вхідний профіль і передача керування

Для завдання j позначимо його вагу через wⱼ, вагу призначення виконавця i через aᵢⱼ. Тоді

```text
P(T = j) = wⱼ / Σₕ wₕ
P(I = i | T = j) = aᵢⱼ / Σₖ aₖⱼ
pᵢ(0) = Σⱼ P(T = j) P(I = i | T = j)
```

Відсутнє призначення означає нульову вагу. Без завдань і явного вектора першим викликається модуль із першого рядка. Явний вектор має N + 2 комірки. Якщо виконання стартує в термінальному стані, відповідна частка вже завершена в момент 0.

Умовна матриця C задає наступний стан серед модулів і SUCCESS за умови, що поточний виклик був успішним. Вага кожного маршруту явно вводиться користувачем. Завдання визначають розподіл першого виклику, а подальшу передачу керування визначає C. Рядок C має суму 1.

## Дискретний час

Для робочого стану i з надійністю rᵢ маємо Pᵢⱼ = rᵢCᵢⱼ для j, відмінних від FAILURE, та Pᵢ,FAILURE = 1 − rᵢ. SUCCESS і FAILURE мають одиниці на діагоналі й нулі в решті комірок. Аналіз обчислює p(k) = p(0)Pᵏ. При k = 0 розподіл дорівнює p(0). Кроки графіка округлюються до цілих значень, повтори вилучаються.

## Неперервний час

Тривалість завершення одного виклику має розподіл Exp(λᵢ) з математичним сподіванням 1/λᵢ. За завершенням виклику обирається результат з рядка P. Для різних станів Qᵢⱼ = λᵢPᵢⱼ. Діагональ Qᵢᵢ = −Σⱼ≠ᵢQᵢⱼ.

Повторний виклик того самого модуля зберігає стан. Якщо Pᵢᵢ > 0, видима інтенсивність зміни стану дорівнює λᵢ(1 − Pᵢᵢ). Це випливає з проріджування пуассонівського процесу завершень. Віртуальні повтори залишаються у вбудованому ланцюгу для підрахунку викликів. Рядки кінцевих станів у Q нульові.

Застосунок обчислює p(t) = p(0) exp(Qt) за SciPy expm. Окремий інтегратор DOP853 розв’язує p′(t) = p(t)Q з тими самими початковими даними. Максимальна абсолютна різниця за компонентами й точками має бути до 2×10⁻⁷. Сталі інтенсивності вимагають однорідності процесу та припущення про відсутність пам’яті. Для залежності від віку або довільних тривалостей потрібен інший клас моделей.

## Метрики й перевірки

- **Перший виклик модуля** — pᵢ(0).
- **Імовірність стану** — pᵢ(h) у заданий момент.
- **Перше досягнення** — Fᵢ(h) = P(Tᵢ ≤ h), де Tᵢ є першим моментом перебування в стані i, з можливим Tᵢ = 0. Тимчасово зробити i поглинаючим і прочитати i-ту компоненту нового розподілу. Для h = 0 результат дорівнює pᵢ(0). Для обраного стану функція доступна на всій сітці. Імовірність першого входу за дискретний крок дорівнює Fᵢ(k) − Fᵢ(k − 1).
- **Очікувані відвідування** — початковий виклик плюс усі входи за повний час місії. Для досяжного транзитного блоку B розв’язується (I − Bᵀ)v = p₀ᵀ. Замкнені рекурентні класи можуть мати нескінченні відвідування. У ручній Q відсутність виходу із стану означає одне відвідування після входу. Якщо система рівнянь погано обумовлена, значення виводиться як недоступне.
- **Успіх, відмова, виконання триває** — pSUCCESS(h), pFAILURE(h) і сума маси решти станів. Успіх і відмова є накопиченими через поглинання.
- **Надійність** — R(h) = 1 − pFAILURE(h) = pSUCCESS(h) + P(виконання триває).
- **Доступність** у моделі з відновленням дорівнює P(система працездатна в момент h). Цей продукт моделює місії з поглинанням, тому показник доступності не виводиться.

Вхідний допуск сум імовірностей 10⁻¹⁰. Для Q використовується |Qᵢᵢ + Σⱼ≠ᵢQᵢⱼ| ≤ 10⁻¹⁰ max(1, Σⱼ≠ᵢQᵢⱼ). Вихідний допуск імовірнісної маси 5×10⁻⁸. Лише залишки округлення в межах допуску нормуються. Перевірка графа знаходить недосяжні стани та замкнені класи.

## Монте-Карло і чутливість

Симуляція починає кожну траєкторію з вибірки p(0). У DTMC наступний стан обирається з рядка P. У CTMC інтервал до видимої зміни стану має параметр −Qᵢᵢ, а наступний стан обирається за Qᵢⱼ/(−Qᵢᵢ). Після горизонту або поглинання траєкторія зупиняється. Для кожної події оцінку k/n супроводжують 95% інтервал Вілсона та різниця з аналітичним значенням. Окремі інтервали є маргінальними.

Чутливість — різниця R(h) між початковою моделлю і моделлю з rᵢ′ = min(1, rᵢ + Δr). Перебір кожного i дає найкращий варіант серед N заданих змін одного модуля з однаковим приростом і обрізанням. Вид пошуку не охоплює одночасні зміни, індивідуальні бюджети чи неоднакові вартості.

## Зв’язок з історичними працями

**Роджер Чеунг.** Опублікована модель використовує профіль користувачів, надійності модулів і виміряні імовірності передачі керування для оцінки успіху сервісу. За тих самих припущень щодо маршрутів і виходу дискретний модульний ланцюг із множниками rᵢ дає ймовірність поглинання в SUCCESS. Для транзитного блоку B і колонки завершення b маємо u = Bu + b, тобто u = (I−B)⁻¹b за умови існування оберненої матриці. Лабораторія використовує споріднену структуру для кінцевого горизонту й окремо показує R(h). Її CTMC і процедура оцінки чутливості є власними реалізаціями, а назва дашборду описує алгоритми через DTMC або CTMC. [Оригінальна праця Чеунга](https://doi.org/10.1109/TSE.1980.234477).

**Пітер Кубат.** Написання «Курбата» в PDF викладача трактовано як можливе посилання на Kubat. Установлено авторство праці 1989 року про стохастичну модель модульного ПЗ. Анотація видавця підтверджує виведення інтенсивності відмови системи та задачу розподілу допустимих інтенсивностей модулів із функцією вартості й цільовою інтенсивністю системи. Повні формули цієї праці доступне джерело не надало. Реалізація перебирає зміни r за фіксованим правилом і документує власну постановку. [Праця Кубата](https://www.sciencedirect.com/science/article/pii/016763778990031X).

**Жан-Клод Лапрі.** Робота про оцінювання в експлуатації відносить надійність, доступність і ремонтопридатність до різних вимірів dependability. Розділ Лапрі та Канун описує спільну інтерпретацію показників на рівні системи та ПЗ. Для процесу з відновленням надійність визначає подія відсутності першої відмови до h, тоді як доступність визначає поточний працездатний стан. Поглинаючий FAILURE у лабораторії дає подію першої відмови. Окремі авторські моделі відмовостійкості й відновлення залишаються в теоретичному огляді. [Праця Лапрі](https://doi.org/10.1109/TSE.1984.5010299), [розділ Лапрі та Канун](https://www.cs.odu.edu/~zeil/cs795SR/Papers/TextBook/Chap_2.pdf).

## Еталони

Базова послідовність із r = [0,99; 0,97; 0,995] має P(SUCCESS до кроку 3) = 0,99 × 0,97 × 0,995 = 0,9554985. У CTMC для всіх трьох модулів λ = 1,5. Час до трьох завершень уздовж траєкторії успіху має розподіл Erlang(3, 1,5), тому P(SUCCESS до t) дорівнює добутку надійностей, помноженому на [1 − e⁻¹·⁵ᵗ(1 + 1,5t + (1,5t)²/2)].

Для рішення про резервування 90% завдань йдуть до основного сервісу з r = 0,95, 10% до резервного з r = 0,99. Після двох кроків успіх дорівнює 0,954. Для безумовного маршруту до основного сервісу він дорівнює 0,95. Результат залежить від вибраних r, навантаження й часу.
