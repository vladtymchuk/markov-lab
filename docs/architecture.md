# Архітектура

Next.js відображає моделі й звертається до версійованого FastAPI через проксі того самого походження. React Query управляє серверними даними, Zustand зберігає тему, а редактори мають робочі копії. Ядро Python отримує типізовані параметри та повертає числові результати без доступу до HTTP і бази.

Проєкт містить змінні назву й архівний стан. Параметри кожного збереження записуються в окрему версію. Сценарій посилається на версію й фіксує параметри аналізу. Запуск містить посилання на версію, повні параметри, результат і метод обчислення. Документ JSONB зберігає узгоджений агрегат модулів, завдань, призначень і переходів. Зовнішні ключі захищають зв’язки між проєктами та історією.

| Шар | Розташування | Відповідальність |
|---|---|---|
| API | apps/api/markov_lab/api | DTO, HTTP, помилки, формати завантаження |
| Застосунок | apps/api/markov_lab/application | Координація збережень, запусків і сценаріїв |
| Домен | apps/api/markov_lab/domain | Модель і обмеження типів |
| Ядро | apps/api/markov_lab/engine | P/Q, динаміка, перше досягнення, Монте-Карло |
| Збереження | apps/api/markov_lab/persistence | SQLAlchemy, транзакції та історія |
| Вебінтерфейс | apps/web | Граф, матриці, запуск, діаграми, сценарії та довідка |

Діаграми в [diagrams](diagrams/) описують повідомлення під час аналізу, джерела даних, доменні класи, компоненти та таблиці.
