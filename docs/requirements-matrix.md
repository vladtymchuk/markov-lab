У Tutorial (с. 1, II.2) текстовий шар PDF повертає символи заміни в місцях кількості модулів і завдань. За фразами «складається з … модулів» і «виконувати … завдань» та основним завданням це дві незалежні величини N і M. У розділі III для бібліографії застосовано числові посилання у квадратних дужках, по одній парі на номер. У User guide вимогу до першого входу реалізує опис локального режиму доступу.
