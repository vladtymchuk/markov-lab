# Локальне розгортання

З кореня репозиторію виконайте `cp .env.example .env` та `docker compose up --build`. Відкрийте `http://localhost:3000`. Документація API доступна на `http://localhost:8000/docs`. Порти можна встановити через WEB_PORT і API_PORT. PostgreSQL використовує внутрішню мережу Compose та іменований том. API застосовує міграції Alembic перед початком обслуговування запитів.

Для зупинки виконайте `docker compose down`. Том з даними зберігається. Для архівації даних використовуйте штатний PostgreSQL `pg_dump` або експортуйте потрібні моделі та запуски через застосунок. Перед зміною PostgreSQL збережіть резервну копію тому.

## Запуск без контейнерів

1. Підготуйте PostgreSQL 17 або сумісний, створіть базу й роль. Встановіть Python 3.12–3.14 та uv.
2. У `apps/api` виконайте `uv sync --locked`. Встановіть змінну `DATABASE_URL=postgresql+psycopg://markov:markov_dev@127.0.0.1:5432/markov` з вашими реквізитами.
3. Виконайте `uv run alembic upgrade head`, потім `uv run uvicorn markov_lab.main:app`.
4. У `apps/web` встановіть Node.js 22 і pnpm 10.33.3. Виконайте `pnpm install --frozen-lockfile`, потім `pnpm dev`. Для іншого порту API задайте API_ORIGIN, а для production встановіть однакове значення під час збирання й запуску.
5. Відкрийте адресу вебзастосунку в браузері. Створення облікового запису в локальному режимі не потрібне.

Порт API й застосунку в Compose опубліковано на loopback. Значення пароля у шаблоні призначене для локальної демонстрації. Для параметрів із зарезервованими URL-символами потрібно правильно кодувати URL PostgreSQL.
